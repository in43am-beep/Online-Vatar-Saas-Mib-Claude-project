👤 The Presenter Secret — Pre-Recorded Real Humans, Not AI

This is the biggest insight. The "AI presenter" is NOT a HeyGen-style AI talking head. It's pre-recorded video footage of real actors, stored on the server. Each presenter has:

  • Multiple clip variants (~10–20 clips each, different expressions, gestures)
  • A full character description: "A 29-year-old Filipina woman, straight black hair in a low ponytail, no makeup, tired but kind eyes, visible skin texture, wearing teal medical scrubs with a stethoscope around her neck" — this is the system prompt for script writer to match voice to character

2 Switch to Gemini Free Tier for Voice + Images

Gemini Free Tier = 1,500 requests/day, free. This is how Frontier keeps cost at $0.03–$0.15/min. Use Google AI Studio API key (free tier).

# Gemini TTS (Flash TTS model) — FREE up to daily limit
import google.generativeai as genai

def gemini_tts(text, voice_name="Puck", out_path=None):
    """Generate voiceover via Gemini TTS — free tier."""
    client = genai.Client()
    response = client.models.generate_content(
        model="gemini-2.5-flash-preview-tts",
        contents=text,
        config=genai.types.GenerateContentConfig(
            speech_config=genai.types.SpeechConfig(
                voice_config=genai.types.VoiceConfig(
                    prebuilt_voice_config=genai.types.PrebuiltVoiceConfig(
                        voice_name=voice_name  # "Puck", "Charon", "Kore", etc.
                    )
                )
            )
        )
    )
    audio_data = response.candidates[0].content.parts[0].inline_data.data
    Path(out_path).write_bytes(audio_data)

# Gemini Image — FREE up to daily limit
def gemini_image(prompt, out_path):
    response = client.models.generate_images(
        model="imagen-3.0-generate-002",
        prompt=prompt,
        config={"number_of_images": 1}
    )
    img = response.generated_images[0].image
    Path(out_path).write_bytes(img.image_bytes)
3 Add Depth Pop Effect (Their $0.004/min Feature)

Their "Depth pop" is a parallax 3D effect. Implementation: use a depth estimation model (free) to get a depth map, then apply FFmpeg displacement filter.

# Depth pop using free DepthAnything model locally:

from transformers import pipeline

def create_depth_map(image_path, out_depth_path):
    pipe = pipeline(task="depth-estimation", 
                   model="LiheYoung/depth-anything-small-hf")
    image = Image.open(image_path)
    depth = pipe(image)["depth"]
    depth.save(out_depth_path)

# FFmpeg zoompan with depth displacement:
def depth_pop_video(img_path, depth_path, duration, out_path):
    ffmpeg.run([
        "-loop", "1", "-i", img_path,
        "-loop", "1", "-i", depth_path,
        "-filter_complex",
        f"[0][1]displace=edge=smear,zoompan=z='min(zoom+0.002,1.3)':d={int(duration*25)}",
        "-t", str(duration), "-r", "25",
        out_path
    ])
